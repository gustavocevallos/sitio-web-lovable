## 🤖 ¿Cómo se generó este proyecto?

**Todo el código de este repositorio fue generado por Inteligencia Artificial.**

No se escribió código manualmente. En su lugar, se utilizó [Lovable](https://lovable.dev) — una plataforma de desarrollo con IA — describiendo en lenguaje natural lo que se quería construir. La IA interpretó esas instrucciones y generó automáticamente el código fuente completo: componentes, estilos, rutas y configuración.

---

## 🚀 Flujo de trabajo completo

```
💬 Instrucciones en Lovable
        ↓
🤖 La IA genera el código automáticamente
        ↓
📦 El código se sincroniza con este repositorio en GitHub
        ↓
☁️  Vercel detecta el cambio y despliega el sitio en producción
```

### Paso 1 — Crear el sitio con Lovable
En [Lovable](https://lovable.dev) se describe el sitio web en lenguaje natural (qué secciones incluir, qué colores usar, qué contenido mostrar). La IA genera el código React completo de forma instantánea y permite seguir refinándolo con más instrucciones.

### Paso 2 — Sincronizar con GitHub
Lovable se conecta directamente con GitHub. Cada cambio generado por la IA se guarda automáticamente como un commit en este repositorio. Así se mantiene un historial completo de todas las versiones del proyecto.

### Paso 3 — Desplegar en Vercel
El repositorio está conectado a [Vercel](https://vercel.com). Cada vez que llega un nuevo commit a la rama `main`, Vercel ejecuta el proceso de build y publica la nueva versión del sitio automáticamente. **Sin intervención manual.**

## 💻 Ejecutar el proyecto en local

Si quieres descargar y ejecutar este proyecto en tu propia máquina:

### Requisitos previos
- [Node.js](https://nodejs.org) versión 18 o superior
- [npm](https://www.npmjs.com) (incluido con Node.js)

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/gustavocevallos/sitio-web-lovable.git
cd sitio-web-lovable

# Instalar dependencias
npm install

# Iniciar el servidor de desarrollo
npm run dev
```

La aplicación estará disponible en https://sitio-web-lovable.vercel.app/

### Scripts disponibles

| Comando | Descripción |
|---|---|
| `npm run dev` | Inicia el servidor de desarrollo con hot-reload |
| `npm run build` | Genera el build de producción |
| `npm run build:dev` | Genera el build en modo desarrollo |
| `npm run preview` | Previsualiza el build de producción localmente |
| `npm run lint` | Ejecuta ESLint para revisar la calidad del código |
| `npm run test` | Ejecuta los tests una vez |
| `npm run test:watch` | Ejecuta los tests en modo observador continuo |

## ☁️ Despliegue en producción

El proyecto está desplegado en **Vercel** con integración continua desde la rama `main`. Cada push genera un nuevo despliegue automáticamente — esto se conoce como **CI/CD** (Continuous Integration / Continuous Deployment).

Para desplegar tu propia instancia:

1. Haz fork de este repositorio
2. Importa el proyecto en [Vercel](https://vercel.com)
3. Vercel detectará automáticamente la configuración de Vite
4. Cada push a `main` desplegará tu sitio automáticamente

## 🎓 ¿Qué conceptos ilustra este proyecto?

Este repositorio está diseñado como material didáctico. Con él puedes aprender y observar en la práctica:

| Concepto | ¿Dónde se ve? |
|---|---|
| **Vibe Coding con IA** | Todo el código fue generado desde Lovable con instrucciones en lenguaje natural |
| **Control de versiones** | Historial de commits en GitHub con cada cambio generado por la IA |
| **CI/CD** | Cada push a `main` desencadena un despliegue automático en Vercel |
| **Stack moderno de frontend** | React + TypeScript + Vite + Tailwind, igual que en proyectos profesionales reales |
| **Entornos de desarrollo** | Local (`npm run dev`) vs. producción (Vercel) |
| **Calidad de código** | ESLint configurado para análisis estático del código generado |
| **Testing** | Scripts de test incluidos en el proyecto |
